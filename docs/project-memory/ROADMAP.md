# Roadmap

## Phase 0 — Foundation
- PMCS in place and green in CI.
- Upstream Horizon revision pinned in UPSTREAM_SYNC.md.
- Scope, stack and platform targets decided in DECISIONS.md.

## Phase 1 — Launcher core
- Minimal launcher core aligned with upstream launcher core.
- Verified build in CI.

## Phase 2 — Engine management
- Fetch, verify, install and update Horizon engine builds.

## Phase 3 — Upstream tracking
- Repeatable procedure to move to newer upstream engine and launcher-core revisions with recorded compatibility results.

## Exit criteria
- Phase 0 is done when PMCS CI is green, the upstream revision is pinned and the scope decision is recorded.
- Later phases get their own exit criteria when they are planned.
